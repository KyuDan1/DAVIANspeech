# v76 결과: 44개 불확실한 음성 부재 손실을 제외하는 것만으로는 부족

동일 EAT 특징·초기 head·6 epoch의 동일 draws로 paired 학습을 완료했다.
수정한 것은 Voice Presence 마지막 weight/bias 193개이며, 검토 대상 44행이 전체
24,576 draws에 나타난 횟수는 67회다. 평가 자료는 학습하지 않았다.

| v73에 적용한 존재 판별 | 개발 File EER | 개발 ADS | 개발 CPS |
|---|---:|---:|---:|
| 변경 없음 | 0.1251625 | 0.8755381 | 0.9990135 |
| 기존 레이블로 학습 지속, control | 0.1258426 | 0.8751980 | 0.9989916 |
| 검토 대상의 부재 손실 제외 | 0.1258426 | 0.8751980 | 0.9990153 |

손실 제외는 control보다 Voice Presence ROC-AUC를 0.00004749 높였지만 File EER은
같았다. 변경 없음보다 File EER이 소폭 악화했으므로 **후보에 반영하지 않는다**.
EAT parent의 나머지 네 열은 정확히 같아 ADS는 0.8378567로 변하지 않았다.

학습 loss 감소를 정확도 개선으로 해석하지 않는다. 이 결과는 검토 플래그가 확정된
레이블 오류라는 증거도, 보컬용 자료 확충이 불필요하다는 증거도 아니다. 고정된 표현의
마지막 선형 출력만 학습한 좁은 개입이며, 개발 CPS에는 이미 ceiling이 있다.
Suno나 긴 보호 평가를 이 실험의 가중치 선택·재평가에 쓰지 않았다.

특징 캐시 초기 출력은 native head와 최대 차이 0, 저장 v73 존재/음악 출력과의 차이는
최대 1.11e-16이었다. 네 GPU 프로세스의 특징 추출과 6 epoch 학습이 실제 종료됐고,
근거는 `reports/presence_repair_v76/full/report.json`이다.
