# v74: 고정 v73 후보의 미사용 긴 음성 검증

## 결과를 보기 전 비교 계획

최고 공식 제출은 `v50_v57m_challenger_v2.zip`의 총점 0.7774307884이다.
새 비교 후보는 개발 4,577개에서 선택한 v73의
`equal_voice_pair_eat_music` 하나로 고정한다. XLS-R/SPEAR 음성 logit 50:50,
EAT의 음악/존재 확률, presence-weighted noisy-OR 파일 확률을 그대로 사용한다.
이번 평가에서 새로운 checkpoint, 결합 가중치, threshold를 탐색하지 않는다.

v73은 전체 개발 ADS 0.87554와 codec 개발 ADS 0.82856을 보였고, codec의 다섯
채널에서 기존 저장 앵커보다 ADS가 높았다. 다만 저장 앵커와 실제 제출 실행의
대응은 `scripts/run_exact_anchor_v74.py`로 먼저 확인한다. 이 스크립트는 기록된
제출 ZIP의 SHA-256을 확인하고, 현재 패키지 파일 크기/CRC를 ZIP과 비교하며,
실행 전후 파일 SHA-256을 검사한다. 원래 `script.py`의 코드는 수정하지 않고
입출력 루트만 별도 실험 디렉터리로 바꾼다. 모델 디렉터리는 읽기용으로 공유한다.

## 고정된 평가 기준

`docs/long-voice-v61-protocol.md`의 조건을 그대로 이어받는다. 원래 검토 대상인
v60은 개발 실험에서 승격되지 않았고, 해당 bank는 탐지 점수를 확인하지 않은 상태로
보존되어 있었다. 이번에는 개발에서 고정한 v73 하나를 평가한다.

- 주 평가: uniform 위치 720파일. 앵커 대비 pooled File EER 최소 1%p 개선,
  길이별/채널별 File EER 악화 최대 2.5%p 이하.
- 별도 대조: 고정 앞/중간/뒤 위치 2,160파일. pooled 및 길이별/채널별 File EER
  악화 최대 2.5%p 이하. 두 bank를 임의 비율로 합쳐 주 지표를 만들지 않는다.
- Voice EER, 녹음 조건, 위치, 길이×채널별 결과도 보고한다. 음악이 없고 존재 라벨이
  상수이므로 이 bank의 Music EER, CPS, 총 ADS/Score는 계산 가능한 대회 점수가 아니다.
- 불확실성은 상관된 변형 파일이 아니라 20개 원천 그룹 단위로 계산한다.
- 통과해도 실제 통화/음악/혼합 일반화나 L4 전체 실행 시간 검증을 대신하지 않는다.
- 실패 결과를 보고 같은 bank에서 후보 가중치를 다시 맞추지 않는다. 원천/파생 파일은
  계속 학습에서 제외한다. 자동 제출하지 않는다.

평가 준비·파일 동등성 검사만으로 이 관문을 통과했다고 보고하지 않는다.
두 모델의 두 bank 전체 예측과 고정 기준 판정이 있어야 실제 비교가 완료된다.

## 평가 시작 전 발견한 캐시 불일치

제출 ZIP SHA-256과 패키지 110파일 크기/CRC 일치를 확인했다. 실제 제출 entrypoint의
개발 8파일 추론도 완료됐으나, 기존 캐시 대비 최대 확률 차이는 File 0.000837,
Voice 0.002417, Music 0.002122로 고정된 0.0005 동등성 허용치를 넘었다.
두 Presence 출력은 일치했다. 이 검사 결과는 **실패로 그대로 보존**하며, 허용치를
늘려 통과로 바꾸지 않는다. 패키지 코드는 바꾸지 않았으며 원인은 아직 확정하지 않았다.

따라서 긴 bank를 열기 전에 `scripts/recompute_exact_anchor_codec_v74.py`로 등록된
codec development 600개를 실제 제출 코드에서 새로 계산한다. 네 독립 프로세스를
같은 GPU에 올리며, 재계산 지표와 첫 8파일의 반복/분할 실행 차이를 함께 확인한다.
v73의 모델/결합식은 이 재계산 중에도 고정한다. 옛 캐시와 실제 baseline이 완전히
같다는 주장은 보류하며, 새 평가의 기준은 파일 검증을 통과한 실제 패키지 출력이다.

재계산 600개를 완료했다. 실제 앵커 ADS는 0.766667, 기존 캐시는 0.766000,
고정 v73은 0.828556이었다. 실제 앵커의 File/Voice/Music EER은
0.233333/0.203333/0.253333이다. 첫 8파일의 재실행/분할 차이는 최대 9.60e-6으로
0.0005 이내였다. 전체 개별 확률의 캐시 차이는 File 0.05919, Voice 0.04365,
Music 0.15423까지 있어 작은 반올림 오차로 일반화할 수 없다. EER 변화가 작다고
옛 캐시와 동등하다고 되돌려 주장하지 않는다.

긴 bank 개봉 전에는 새 실제 앵커 대비 개발 전체 ADS 개선 1%p 이상과 다섯 채널
각각의 ADS 비악화를 확인한다. 고정 v73 외 다른 모델을 여기서 추가 탐색하지 않는다.
그 뒤의 긴 bank 판정 기준은 위의 File EER 관문 그대로 유지한다.

새 실제 앵커 산출물: `reports/exact_anchor_v74/codec_recomputed/`.
Suno의 별도 고정 감사에서 드러난 보컬 확률 문제는 `docs/suno-frozen-v73-audit.md`에
기록했다. 그 결과를 보며 v73을 변경하지 않았으며, 긴 음성 비교가 통과하더라도
보컬곡 성분 판단 문제가 해결됐다고 주장하지 않는다.
